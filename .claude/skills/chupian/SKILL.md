# 出片

判断标准只有一个：**和对标的爆款放在一起，我们这条更想让人看完吗？**靠并排对比回答，不靠清单打勾。

## 底线（硬性）
- 数字真实，有一手出处（论文、官方数据）；不夸大、不误导
- 不搬运别人的画面素材；同选题不照搬原片的句子、金句和独有比喻
- 配乐只用你有权使用的：平台曲库里的曲子（发布时挂上）、可商用素材，或者自己做的
- 发布、回复评论只由 `_流水线/ops/runner.js` 执行（限速写在代码里）；做片环节只写文件，不调用发布和回复命令
- 只动自己的账号：不去别人视频下评论，不批量关注/点赞/私信，不刷量

## 动手前必过
1. **一句话说出这条的「居然」**：观众听了会反问「真的假的？」。它同时是标题、封面、第一秒画面和第一句字幕。人人都知道的事一句带过或不讲。
2. **有正在起量的爆款，先做它的续集**（`_流水线/ops/data/hot.md`），24～48 小时内上线，顺着爆点往深挖。
3. 时长按你的数据定（短知识片一般 30～40 秒）；每 2～3 秒一个新信息，答案往后放。

## 流程
1. **找一条想超越的爆款。**`_流水线/scan.sh` + `rank.py` 抓话题下最新视频，按每小时点赞排出正在涨的。选一条有把握做得更好的。
2. **把它拆透。**下载原片，用 `sheet.py` 拼联系表，看关键镜头原尺寸截图，弄清它为什么让人看完：画面、节奏、故事、声音。写几句话说清楚。
3. **想清楚好在哪。**内容更扎实、故事更好、画面更美？说不出来就换一条。资料查原文（`pdftotext`），写进 `脚本.md`。
4. **开头 10 秒样片。**和原片开头上下并排（`ffmpeg ... vstack`）比，先改开头。
5. **全片。**再和原片并排看一次；自评流程见 `_流水线/ops/prompts/produce.md`。
6. **发布后看数据。**6 小时、24 小时只读抓创作者中心（`stats.js`），学到的写进下面的经验库，写成「观察 + 证据」，被新数据推翻就改。

## 经验库（参考，不是规则；复盘时由 Claude 自己往里补）

**开头**
- 第一帧就要亮、有一个一眼看得清的主体；不渐入、不暗场。逐秒留存里最容易比同类多掉的是第 1 秒
- 钩子之后不要停顿：片名卡、黑场、慢镜头都会在第 4～7 秒掉一截，直接接下一个信息
- 常见有效开头：先说一个大家都信的说法，再推翻它

**中段**
- 每 2～3 秒要有新信息或画面变化，不铺垫、不重复钩子
- 小而具体的例子当场「算出来」能留人；从小例子切到抽象大图时，要接一个新问题
- 答案别在钩子里给掉；同一个结论换个比喻再讲一遍、静态卡挂太久，都会让中段掉得很快
- 大字数字卡 2～3 秒就够

**文案**
- 标题 ≤20 字、第二人称、有痛点、不说答案
- 选题优先「被冤枉 → 翻案」，分享率明显高于讲机制
- 锚词（2～4 字、是处境不是术语）反复出现；高潮前一句话只说一半；结尾抛一个人人有答案的问题，大字挂到片尾
- 每句字幕 ≤18 字；手机上 1280 宽设计稿里 22px 以下的字基本看不清
- 发前自问：标题会不会剧透、有没有歧义或网络双关、数字会不会被误读

**卡点和声音**
- 按配乐的拍子做：重拍前约 0.75 秒收暗、最后 3 帧定住，重拍那帧砸出锚词；重拍前 2 秒加 riser、重拍加 impact；开场几下重音每下画面发生一件事
- 整片响度约 -13～-15 LUFS，真峰值 ≤ -1
- 观众会认话题里常用的那类配乐；自配的小调氛围音乐可能被评论「音乐不对」

**画面**
- 代码渲染：`render(t)` 纯函数 → Playwright 逐帧截图 → ffmpeg。平面/线条用 Canvas 2D，立体/粒子用 Three.js
- 正式渲染前每秒出一张静帧，能提前抓到报错（负半径、`%` 对负数）
- 每期设计 3～5 个只属于这个选题的出彩点：一个贯穿全片的小世界、会动的角色、把推理变成实物（天平、计数器）
- 火柴人加图表的画面容易被说「像 PPT」
- 自查：每个镜头切走前的那一帧拼成一张图；重拍前后各看几帧；中段抽帧确认画面在动

**封面**
- 代码专门渲染，不要截成片的帧（平台会提示「请勿使用截屏当封面」）
- 有效配方：深色底、大标题、关键词换色、问句副题、一行悬念或数字（必须和片中一致）、一个可爱的主体
- 续集沿用跑出来的那张封面的配方，只换文字和道具；平台「封面检测通过」只查技术，不代表好看

**发布（网页版创作者中心）**
- 上传前 ffprobe：统一 `-level 4.1 -ac 2 -pix_fmt yuv420p -movflags +faststart -b:v 8M`；单声道或 H.264 level 5.0 会「上传失败」
- 横竖两张封面都要传；竖封面传错上传框会同步横封面、裁掉字（细节见 `sau_publish.py`）
- 成片里带了某首曲子，发布时就要在曲库挂上同一首，否则会被标成你的「原声」

**复盘**
- 数据接口和字段见 `stats.js` 注释：2 秒跳出、5 秒完播、同类对比、逐秒留存、逐时播放
- 短视频的播放大多集中在发布后几小时内，6 小时播放基本就是这条的量级；个别作品会在之后被二次推荐
- 播放转化成粉丝是单独的问题：复盘时同时看「每千播放涨粉」，不只看播放
